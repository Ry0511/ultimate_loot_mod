#
# Expecting a comma separated list of arguments:
#   [0] override_path       - The path to the mission or mission reward to override
#   [1] reward_path         - The path to the custom mission reward
#   [2] is_loot_pool_reward - Is the reward an ItemPoolDefinition or an InventoryBalanceDefinition?
#   [3] is_mission_override - Is this reward overriding the mission or a generic reward?
#   [4] zippy               - The type of item the reward is required to produce it should be a comma
#                             separated list of 0 or more elements.
#                             Valid values are: All, ClassMod, Revolver, AssaultRifle, Shield, Shotgun,
#                                               GrenadeMod, Launcher, Sniper, Repeater, SMG, Eridian
#
# Processing of arguments 2, 3, 4, ..., N assumes the following:
#   first found bool true/false value is is_loot_pool_reward
#   second found bool true/false value is is_mission_override
#   anything else is one of any zippy type
#
# NOTES
#   [0] Is either an absolute path to a MissionDefinition or an InventoryBalanceDefinition where
#       said balance definition is the reward for a mission. If a mission override exists then that
#       takes priority for that specific mission.
#
#   [1] The reward can be either an ItemPoolDefinition or an InventoryBalanceDefinition the latter
#       is kinda redundant as thats what the mission gives anyway. If a loot pool is provided then
#       an item will be spawned from the loot pool and the InventoryBalanceDefinition will be passed
#       forward (this allows it to respect the normal loot pool spawning process). Additionally, if
#       a zippy is provided then we will spawn items from the loot pool until we get an item that
#       matches one of the zippy types provided.
#
#   [2,3] These are not required to be provided; if they are provided they are taken as is, if they
#         are not provided then it will attempt to auto-detect.
#
#   [2,3,4] Are all case-insensitive
#
# Two console commands exist to assist in testing:
#   1. `reload_rewards` which will reload the reward file
#   2. `cheat_missions` which when called will force every missions state to be ready to turn in;
#       except story missions which it will mark as completed. This will mess with your savefile so
#       make it readonly if you don't want it to mess with things.
#
